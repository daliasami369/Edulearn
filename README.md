# 🎓 Edulearn – Online Learning Platform

Edulearn is a full-stack online learning platform developed using Django. It provides an interactive environment for both teachers and students, allowing educators to manage courses, lessons, and assessments while giving students easy access to learning materials and online exams.

## 🚀 Key Features

- 👨‍🏫 Teacher & Student authentication
- 📚 Course and lesson management
- 🎥 Video and PDF lesson support
- 📝 Online quizzes and examinations
- 📊 Interactive teacher dashboard
- 👥 Student enrollment system
- 📢 Announcements
- 💬 Communication features
- 🔐 Secure authentication and authorization
- 📱 Responsive user interface

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- MYSQL

## 🎯 Purpose

The project was built to simulate a real-world e-learning platform where teachers can organize educational content and students can access learning resources in a structured and user-friendly environment.
